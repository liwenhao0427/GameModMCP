**实测**（构造 Hook 卸载、`script.unload()`、`session.detach()` 三者全部抛异常）：

```

→ 卸载 Hook / unload / detach 三个动作全部抛异常，仍报 restored = True
```

**影响**：这是全部工具里最危险的一条。`close_session` 的官方定位是「把游戏恢复原状」，

**一句话修复**：把三个 `except Exception: pass` 收集成错误列表，任一步失败即
`return {"ok": False, "error": ..., "restored": False}`，只有三步都成功才给 `restored: True`。

#### 4. `class_hierarchy` 把任意深度的后代标成 `depth=1` 且 `parent` 写错 —— 类别 A（返回错误数据却 `ok: True`）

`src/gamemod_mcp/engine/index.py:1153-1165`

```python
1153:            while frontier:
1154:                cur, lvl = frontier.pop(0)
1155:                if lvl >= depth:
1156:                    continue
1157:                for d in m.find_derived(cur.nested_name, limit=500):
1158:                    if d.index in seen:
1159:                        continue
1160:                    seen.add(d.index)
1161:                    tree.append({"name": d.nested_name, "depth": lvl + 1,
1162:                                 "parent": cur.nested_name})
1163:                    frontier.append((d, lvl + 1))
1164:            result["down"] = tree
1165:            result["down_count"] = len(tree)
```

根因：`find_derived`（`il2cpp_meta.py:997-1007`）是**传递式**查询（返回全部后代，含间接），
而 BFS 把它当成「直接子类」用。于是根节点的第一层被塞进 500 条任意深度的后代，
全部标 `depth=1`、`parent=<root>`。

**实测**（`full_name="UnityEngine.MonoBehaviour"`，`direction="down"`，`depth=1`）：

```
真实直接子类数 = 428
标为 depth=1 的条目数 = 500
  其中确实是直接子类的 = 181
  其中并非直接子类的 = 319 (被错误标成第 1 层，parent 也写成 MonoBehaviour)
  真实直接子类里根本没出现的 = 247
find_derived 传递式无上限 = 1548
```

单条样例：

```
class_hierarchy 报告的条目: {'name': 'ChapterE3_FinalBossCorridor', 'depth': 1, 'parent': 'UnityEngine.MonoBehaviour'}
该类型的真实父类: TeamTapas.ProjectR.GameLevels.Impl.GameLevel_Mirror_Fight_Base
是否直接继承 MonoBehaviour: False
```

**影响**：这是本次审查中**数据本身错误**最严重的一条，且与「截断」无关。
Agent 用 `class_hierarchy(down)` 的核心目的就是「逐层摸清继承树、找直接子类」；
本工具对一个类报告了 500 个 `depth=1` 子类，其中 **319 个不是子类**（`parent` 字段是编造的），
而 **247 个真实直接子类根本没出现**。Agent 会据此得出完全错误的继承结构，并可能把
不存在的父子关系写进 Hook 方案。返回键只有 `['down','down_count','found','ok','root']`，
**没有 `has_more`/`truncated`**，`down_count` 也只是「它自己数了多少」，Agent 无法察觉异常。

**一句话修复**：`down` 的每一层改用「取直接父类等于 `cur`」的判定
（`il2cpp_meta.parent_of` / `adapt.parent_name`）而非 `find_derived`，并对每层超限如实给 `has_more`。
