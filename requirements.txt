#        dotnet tool install --global ilspycmd
#
#   2) 弱视觉（截图 + OCR）—— 看 `get_diagnostics.screen`
#        截图（二选一，dxcam 对全屏独占更稳）：

#          pip install mss
#        OCR（二选一，rapidocr 中文更好）：
#          pip install rapidocr-onnxruntime
#          # 或装 Tesseract-OCR（含 chi_sim 语言包）+ pip install pytesseract
#        按窗口标题定位还需要：
#          pip install pywin32
#
# 装上后无需任何配置：capture_screen / ocr / probe_log 立即可用。
